# Quran Video Studio — Starter\n\nمشروع تأسيسي بواجهة عربية RTL باستخدام React وTypeScript وVite.\n\n## التشغيل\n1. تحتاج بيئة Node.js وnpm.\n2. نفّذ `npm install` ثم `npm run dev`.\n3. للبناء: `npm run build`.\n\n## الموجود الآن\n- واجهة متجاوبة.\n- تعديل النص والخط واللون والحجم والشفافية والتعتيم.\n- اختيار صورة/فيديو خلفية محلية ورفع ملف صوت وتشغيله.\n- تنزيل إعدادات المشروع بصيغة JSON.\n\n## غير مكتمل بعد\nلا يوجد حتى الآن مصدر موثوق كامل للقرآن أو مكتبة تلاوات متصلة، ولا مزامنة آلية دقيقة، ولا Timeline فعلي، ولا تصدير MP4. لا تعتبر نص المعاينة الافتراضي مصدرًا قرآنيًا معتمدًا. ملف الإعدادات لا يتضمن ملفات الوسائط. تحقق من تراخيص جميع المواد قبل النشر.\n
